# Tasogare 黄昏 自选延迟 GPU 版

当前版本：`v2.2.2`

## v2.2.2 修复

- 修复第三条 TCPing 历史点阵紧贴底部网速分隔线的问题。
- 在 TCPing 区域末尾加入固定安全间距，确保最后一行点阵完整显示。
- 底部网速和在线时长状态栏不再参与压缩，窄屏及高 DPI 下保持稳定间距。

## v2.2.1 修复

- 修复窄卡片与高 DPI 显示下 TCPing、实时网速、在线时长和标签的边界错位。
- 节点卡片改为弹性纵向布局，底部状态栏始终留在卡片内部。
- 延迟和丢包两列增加安全的最小宽度与文本收敛规则，避免互相挤压或溢出。
- 外层节点卡片改为键盘可访问的语义容器，避免嵌套按钮结构。

本项目基于 [tryingmeow/komari-theme-tasogare](https://github.com/tryingmeow/komari-theme-tasogare) 修改。当前代码基线为 Tasogare `v1.2.2`，并保留本项目现有的自选延迟、丢包详情、连接数、剩余价值与访问 IP 等增强功能。

## v2.2.0 主要更新

- 服务器详情完整显示 CPU 型号；
- 新增 GPU / iGPU 详情，支持独显、Intel/AMD 核显与多 GPU 数据；
- GPU 型号自动精简，例如 `Intel Corporation CometLake-S GT2 [UHD Graphics 630]` 显示为 `Intel UHD Graphics 630`；
- 过滤 Sensor Hub 等非显卡设备，避免 GPU 误识别；
- 显示 GPU 使用率以及显存/共享内存，无 GPU 节点自动隐藏；
- 服务器详情面板不再显示延迟图；
- 首页点击延迟区域打开的独立延迟/丢包弹窗保持不变；
- 新增按月流量周期计算，避免累计流量长期显示 100%；
- 支持全局流量重置日，以及通过节点标签为单台服务器单独覆盖。

## 延迟展示逻辑

首页卡片与点击弹窗采用两套范围：

- **首页卡片**：用户从 Komari 已创建的延迟任务中自由选择 `0～3` 项；
- **点击延迟区域**：打开独立弹窗，展示当前节点被分配的全部延迟监测任务，不受首页 0～3 项选择限制。

TCP、ICMP、HTTP 可以任意混合。每个首页展示项严格对应一个任务，不会把不同城市或不同任务自动平均。

## 卡片名称

首页自动压缩运营商名称并显示协议徽标：

```text
广东联通 TCP  → 广东·CU  [TCP]
广东电信 ICMP → 广东·CT  [ICMP]
广东移动 TCP  → 广东·CM  [TCP]
东京 TCP      → 东京     [TCP]
```

也可以在选择器中填写自定义名称。丢包列不再重复显示任务名称，只保留数值和状态条，使左右两列更整洁。

## 点击延迟详情

点击卡片延迟区域后：

- 加载该节点全部可用延迟任务；
- 显示历史延迟折线与对应丢包/断连状态；
- 支持单独隐藏线路、全选和全不选；
- 只显示延迟与丢包事件，不显示 CPU、内存、流量等硬件详情；
- 点击关闭按钮、遮罩或按 Esc 关闭。

## GPU / iGPU 详情

点击服务器卡片打开节点详情后：

- CPU 型号完整显示；
- 检测到真实 GPU 时才显示 GPU、GPU 使用率和 GPU 显存；
- Intel/AMD 集成显卡没有独立显存时显示“共享内存”；
- 无 GPU 的服务器不会显示空白 GPU 项目；
- Sensor Hub、Management Engine 等非显卡设备会被过滤。

## 每月流量周期

主题设置中的 `trafficResetDay` 可填写 `1～28`，表示每月流量周期的重置日。

例如填写 `13`，卡片会按每月 13 日开始的新周期计算当前周期已用流量，而不是直接显示 Agent 的长期累计流量。

如果不同服务器重置日不同，可以给节点添加标签：

```text
traffic-reset:13
```

该标签会覆盖该节点的全局 `trafficResetDay` 设置。

## 其他增强

- TCP / UDP 连接数；
- 顶部剩余价值与汇率悬浮面板；
- 延迟、丢包历史状态条；
- 自选任务保存在当前浏览器；
- 主题后台可配置全站默认任务与名称；
- 首页底部显示访问者公网 IP，可在主题设置中关闭或替换查询接口。

本项目继续遵循原项目许可证。
