# Tasogare 黄昏 自选延迟版

当前版本：`v2.0.0`

本项目基于 [tryingmeow/komari-theme-tasogare](https://github.com/tryingmeow/komari-theme-tasogare) 修改。感谢原作者及所有贡献者的开发、维护与开源分享。

## 延迟展示逻辑

首页卡片与悬浮详情采用两套范围：

- **首页卡片**：用户从 Komari 已创建的延迟任务中自由选择 `0～3` 项。
- **鼠标悬停详情**：展示当前节点被分配的**全部延迟监测任务**，不受首页 0～3 项选择限制。

TCP、ICMP、HTTP 可以任意混合。每个首页展示项严格对应一个任务，不会把不同城市或不同任务自动平均。

## 卡片名称

首页自动压缩运营商名称并显示协议徽标：

```text
广东联通 TCP  → 广东·CU  [TCP]
广东电信 ICMP → 广东·CT  [ICMP]
广东移动 TCP  → 广东·CM  [TCP]
东京 TCP      → 东京     [TCP]
```

也可以在选择器中填写自定义名称。丢包列不再重复显示任务名称，只保留数值和状态条，使左右两列更整洁。

## 悬浮详情

鼠标进入卡片延迟区域后：

- 加载该节点全部可用延迟任务；
- 显示 1 小时、6 小时、12 小时、1 天、7 天历史折线；
- 支持单独隐藏线路、全选和全不选；
- 只显示延迟数据，不显示 CPU、内存、流量等内容；
- 鼠标离开卡片与悬浮面板后自动关闭。

## 其他增强

- TCP / UDP 连接数；
- 顶部剩余价值与汇率悬浮面板；
- 延迟、丢包历史状态条；
- 自选任务保存在当前浏览器；
- 主题后台可配置全站默认任务与名称。

## 安装

下载 Release 中的 Komari 安装包，在 Komari 后台进入主题管理并直接上传 ZIP，不要解压。

本项目继续遵循原项目许可证。
